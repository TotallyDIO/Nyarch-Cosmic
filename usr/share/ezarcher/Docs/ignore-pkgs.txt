Ignore Packages - Mitigaing possible AUR malware

In an attempt to help prevent certain malware from being unwittingly installed via AUR packages,
I have listed a few specific packages in the IgnorePkg: section of the pacman.conf file used in 
the construction of Ezarcher.

The packages listed to ignore are: yarn bun pnpm npm nodejs node-gyp nvm

yarn: Fast, reliable, and secure dependency management.
   This program has been linked to various Linux malware projects, i.e.: "Spinning YARN."

bun: JavaScript runtime, bundler, test runner, and package manager – all in one.
   Bun has not yet been widely seen in malware campaigns, and it allows them to package malicious
   code into larger executables that may be less easily detected. 

pnpm: Fast, disk space efficient package manager.
   Sometimes npm packages are compromised and published with malware. pnpm v10 disables the
   automatic execution of postinstall scripts in dependencies. Although there is a setting
   to re-enable them globally using dangerouslyAllowAllBuilds, we recommend explicitly listing
   only trusted dependencies using allowBuilds.

npm: JavaScript package manager.
   Sometimes npm packages are compromised and published with malware. Historically, most
   compromised packages have used postinstall scripts to run code immediately upon installation.

nodejs: Evented I/O for V8 javascript.
   Threat actors are now leveraging compiled JavaScript—or even running the scripts directly
   in the command line using Node.js—to facilitate malicious activity.

node-gyp: Node.js native addon build tool.
   A supply chain attack is actively spreading through the npm registry by abusing a file
   most security tooling never looks at: binding.gyp. Instead of relying on the well-monitored
   preinstall or postinstall lifecycle scripts, the malware ships a weaponized binding.gyp
   that triggers node-gyp to execute attacker-controlled code automatically during npm install.

nvm: Node Version Manager - Simple bash script to manage multiple active node.js versions.
   Nvm is a version manager for Node that allows you to switch between node versions. Nvm itself
   is safe to use (and almost mandatory). What could be unsafe is the packets you download for
   your projects through Node's package manager (NPM). 

These are certainly not all of the possible threat vectors, but recent malware insertions into the AUR
point to these packages / programs as newly utilized methods to distribute malware attacks. 

These packages were never part of an Ezarcher install, so setting pacman.conf to ignore these
packages does not change Ezarcher or its components. If you find valuable use for any of these packages,
merely remove their names form the IgnorePkg: line in your pacman.conf.
